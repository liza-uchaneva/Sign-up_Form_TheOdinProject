# Sign-up Form

A sign-up page with client-side form validation, built for [The Odin Project](https://www.theodinproject.com/).

## Features

- Styled form with valid and invalid input states
- Built-in HTML validation through input types (`tel`, `password`) and a `pattern` attribute
- **Password confirmation check** in JavaScript: when you leave the confirm field and the passwords don't match, it shows an error (using `setCustomValidity`)

Open `index.html` in a browser.
